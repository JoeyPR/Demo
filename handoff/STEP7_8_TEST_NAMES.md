## Step 8 blend (test/xml-blend.test.mjs): 22 tests

- 8.1 BLEND_PREMULT_MODE is one named constant, one of off/A/B, and defaults to off (legacy straight alpha)
- 8.1 setBlendPremultMode switches at runtime and rejects unknown modes
- 8.1 the XML blendingMode names map to three kinds: ADDITIVE additive, PREMULTIPLIED_ALPHA premult, NORMAL/PREMULTIPLIED_NORMAL/absent normal
- 8.1 every blendingMode value shipped in the XML is known to BLEND_KIND
- 8.2 plan: additive is always 'lighter' on the plain crop, in every mode
- 8.2 plan: normal calls are source-over on the plain crop in every mode
- 8.2 plan: premult is plain source-over in off, one premultiplied source-over in A, destination-out + lighter(opaque RGB) in B
- 8.2 plan: with no mode argument the current global mode is used
- 8.3 pixels: premultiplyPixels multiplies RGB by alpha and keeps alpha
- 8.3 pixels: opaqueRgbPixels keeps straight RGB, forces alpha 255 and does not divide or multiply
- 8.4 maths A: out = rgb*a*a + dst*(1-a) (art premultiplied once, then source-over)
- 8.4 maths B: out = rgb + dst*(1-a), the GL ONE, ONE_MINUS_SRC_ALPHA result on straight RGB
- 8.4 maths: A and B differ on a half-transparent pixel (A is darker) and agree on a fully opaque one
- 8.4 maths: call alpha (piece opacity) scales A and B consistently (B: rgb*alpha + dst*(1-a*alpha))
- 8.4 maths: 'off' equals the legacy path (straight source-over): rgb*a + dst*(1-a)
- 8.5 drawCanvas runs the premult plan per mode: off=source-over/atlas, A=source-over/premult crop, B=destination-out then lighter/opaque crop
- 8.5 drawCanvas: additive and normal calls draw the same in every mode (no derived crops requested)
- 8.5 drawCanvas: an atlas adapter without blendCrop fails loudly in A/B instead of silently drawing straight alpha
- 8.5 drawCanvas without a blendMode option uses the global mode
- 8.6 an XML particle with blendingMode PREMULTIPLIED_ALPHA / ADDITIVE / NORMAL / absent carries blend premult / additive / normal / normal
- 8.6 xml-support: Particle.blendingMode stays partial (the A/B choice is not verified)
- 8.7 UI: the page has the three-way Particle blend control, wired to setBlendPremultMode and to drawCanvas
