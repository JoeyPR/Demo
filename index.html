READING THE DEMO

A reference, not a recovered client.

This demo uses real player and clothing sprite pieces served by Set Planner GT, plus the source-derived walk tables, affine rig, arm pivots, layering and tint pipeline from the research handoff.

The complete public catalog snapshot contains 4,081 wearables across ten slots. This is not a claim that every item released in the official game is present. All entries can be searched and equipped; missing scripts and FX remain explicitly unsupported.

Riding retains seat sprites, uses a shared root for floating mounts, and resolves idle versus moving versus punching poses. Split horse-sit mounts have a movement-only reference hop with opposing halves. One-piece 64px mounts are excluded. The hop amplitudes and timing are reference tuning, not recovered official constants.

Known item-driven lift profiles apply automatically. Fifty dynamic profiles agree with public still offsets and use source-derived one-second cycles. These are default-state source comparisons, not proof of every outfit combination or of missing native scripts. Large frames, clock sequences, additive blending and public flicker/pulse effects have separate handling.

The supplied player archive adds 314 parsed XML renderer definitions. Matched sprite tracks, selected aura render rules and public pet-cell clocks now run. Parsed definitions do not imply full native support: complex state rules, particle behavior and pet AI remain partial.

  • Numerically compared: selected planner walk-arm sampling and transform functions.
  • Preview only: flat-floor movement, generic punch, follower motion and outfit combinations.
  • Illustrative: weather scenery, hover override and generic jump particles. These are not per-item official FX.
  • Not included: every native XML operation, full world collision or an official-client pixel comparison.

Output buttons change the avatar render buffer, not the physics. The PNG export is a transparent 4 × 4-tile viewport at the selected pixels per tile.

Reference: Set Planner GT · Inspected bundle · Public item catalog
